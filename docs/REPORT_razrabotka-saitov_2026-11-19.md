## 1. Резюме

**Технических блокеров индексации нет.** Все 24 URL из sitemap отдают 200, canonical совпадает, robots разрешает обход, SSR-рендер полный, schema валидна, TTFB 36–126 мс, битых внутренних ссылок 0 из 59.

**По теме «разработка сайтов» сайт не ранжируется вообще — и причина не в технике, а в четырёх вещах:**

1. **Нулевое покрытие спроса.** За 90 дней в GSC **14 запросов на весь сайт** и **ни одного** со словами «разработка сайтов» / «создание сайтов» / «заказать сайт». Деньги-страница `/uslugi/razrabotka-saitov` за 90 дней собрала **6 показов** и 0 кликов.
2. **Нет внешних сигналов.** Домену ~7 недель (данные GSC с 30.09.2026). Брендовый запрос «zaiko» — 2 показа. Внешних упоминаний домена не найдено.
3. **Один URL на весь кластер против 70–462 URL у конкурентов.** Нет страниц под синонимы («создание сайтов», «заказать сайт»), под города (Гомель, Гродно, Витебск, Брест, Могилёв) и под ниши.
4. **On-page не совпадает с интентом головного запроса.** На главной в title/H1 нет «разработка сайтов», H1 набран капсом, анкор на деньги-страницу — «Заказать под ключ →», а на самой странице 0 вхождений «заказать сайт» и 0 отзывов.

**Главный вывод:** сайт проигрывает не «скоростью и метатегами», а объёмом и авторитетом. Пока на домене 24 страницы, 5 кейсов и ни одной внешней ссылки, топ-10 по «разработка сайтов» недостижим — там агентства с 10+ годами и сотнями работ.

## 3. Критические места (по приоритету)

### Б1. Нулевое покрытие темы в Search Console — блокер №1
**Проблема:** за 90 дней ни одного запроса по «разработка сайтов»/«создание сайтов»/«заказать сайт». Страница есть в индексе, но не участвует в выдаче по теме.
**Влияние:** высокое — без показов нет позиций, нет кликов, нет обучения алгоритма.
**Доказательство:** полный список 14 запросов за 90 дней (п. 2.2) — темы в нём нет; `/uslugi/razrabotka-saitov` — 6 показов/90 дней.
**Причина (не техника):** молодой домен без ссылочного и брендового веса + единственная страница на конкурентный кластер.
**Что делать:** наращивать кластер страниц (Б3) и внешние сигналы (Б2), а не править метатеги.

### Б2. Нет внешних сигналов и бренда
**Проблема:** сайт не упоминается вне себя. Поиск домена в вебе (`site:evgeny-zaiko.by` через Serper) вернул 0 результатов при том, что GSC подтверждает индексацию. Брендовый запрос «zaiko» — 2 показа за 90 дней.
**Влияние:** высокое. Для коммерческого запроса «разработка сайтов» Google ранжирует сущности, а не тексты: без ссылок/упоминаний/отзывов на внешних площадках страница не поднимается.
**Доказательство:** GSC query «zaiko» — 2 показа, поз. 4,5; SERP-запрос по домену — пусто; ни одного внешнего упоминания в выдаче.
**Что делать:** карточки в каталогах веб-студий, профили (LinkedIn/Behance/Дев.бай/Куфар-услуги), гостевые кейсы, ссылки с проектов портфолио (korneplod.by и др. — свои сайты со ссылкой в футере).

### Б3. Один URL на весь кластер «разработка сайтов»
**Проблема:** тему закрывает ровно одна страница `/uslugi/razrabotka-saitov`. Синонимы и гео не покрыты.
**Влияние:** высокое. Конкуренты собирают тему сотнями страниц (услуга × город × ниша × кейс).
**Доказательство:** из 24 URL только у одной страницы «разработка сайтов» в title; запросы «создание сайтов» (0 вхождений на странице), «заказать сайт» (0), города кроме Минска (0). `google_suggest` показывает спрос по Гомелю, Гродно, «в минске», «на cms».
**Что делать:** страницы под «Создание сайтов» (синоним-хаб), города (Минск, Гомель, Гродно, Витебск, Брест, Могилёв — по приоритету спроса), ниши (сайт для стоматологии/салона/завода), отдельные страницы кейсов.

### Б4. On-page не совпадает с интентом головного запроса
**Проблема (по факту прод-HTML):**
- Главная: title «Сайты с заявками под ключ — для русского бизнеса | Зайко» — нет «разработка сайтов», формулировка «для русского бизнеса» уводит от BY-интента.
- Главная: H1 «САЙТ С ЗАЯВКАМИ ПОД КЛЮЧ» капсом, разбит на 20 letter-span'ов (`hero__ch`), ключа темы в нём нет.
- Анкор с главной на деньги-страницу: «Заказать под ключ →» — не описывает тему.
- Деньги-страница (1077 слов): «заказать» — 0, «создание сайт» — 0, «цена» — 1, «стоимость» — 1, «срок» — 1, «Минск» — 1, «отзыв» — 0, «гарант» — 0.
  (при этом «разработка сайтов» — 20 вхождений, H1 корректный: «Разработка сайтов под ключ»)
**Влияние:** среднее-высокое. Сама страница оптимизирована, но её вес не подкреплён главной, а коммерческие модификаторы интента почти не отражены.
**Что делать:** в H1 главной и/или title добавить «разработка сайтов»; анкор с главной сделать описательным; добавить на страницу блоки «заказать сайт», цены/сроки таблицей, гарантии/договор.

### Б5. Нет доказательств (E-E-A-T)
**Проблема:** 5 кейсов на одной странице `/cases` (598 слов), отдельных страниц кейсов нет. Отзывов нет нигде (0 вхождений на `/`, `/about`, `/cases`, `/ceny`). В футере только «© Евгений Зайко · EVGENY-ZAIKO.BY», без юрлица/УНП/адреса. `/about` — 336 слов. На странице услуги **0 изображений** (0 тегов `<img>`).
**Влияние:** среднее. Для коммерческих запросов «заказать сайт» доверие — прямой фактор CTR и удержания; отсутствие отзывов и юрлица снижает конверсию и сигналы качества.
**Что делать:** страницы кейсов с цифрами и скриншотами, блок отзывов (даже со скриншотами из Telegram), реквизиты в футере, расширить `/about` до полноценной страницы эксперта.

### Б6. Яндекс: сайта фактически нет в индексе
**Проблема:** по аудиту от 11.11.2026 Яндекс.Вебмастер отдавал `searchable_pages_count: 0`, `sqi: 0`, sitemap скачан 08.10 с 17 URL (на проде уже 24).
**Влияние:** высокое для рынка Беларуси — Яндекс даёт существенную долю поиска. **Сегодня не перемерялось** (нет доступа к токену в этой сессии) — цифру нужно подтвердить перед планированием.
**Что делать:** переотправить sitemap в Вебмастере, проверить «Индексирование → Страницы», добавить регион, добить коммерческие факторы (контакты, реквизиты, отзывы).

### Б7. Контент встал
**Проблема:** 9 статей, все опубликованы 04.10–03.11.2026, с 03.11 публикаций нет. Блог даёт почти весь видимый спрос (18 из 42 показов — один пост), но тематически не связан с «разработкой сайтов».
**Влияние:** среднее. Регулярность важна и для обхода, и для тематической полноты.
**Что делать:** вернуть ритм 1–2 материала в неделю, темы брать из `google_suggest` и PAA по «разработка сайтов» («сколько стоит разработка сайта», «этапы разработки», «разработка сайта на cms или под ключ»), связать каждый материал с деньгами-страницей.

## 6. Ограничения измерений

1. **Живой SERP с позициями.** Инструмент `serp_check` в google-seo-mcp требует `DATAFORSEO_LOGIN/PASSWORD`, которых на хосте нет. Топ-10 собран через Serper-поиск, без фиксированных позиций и без блока People Also Ask / AI Overview. Для отчёта этого достаточно, для трекинга позиций — нет.
2. **CWV.** PageSpeed Insights вернул 429 (дневная квота проекта исчерпана — та же ошибка, что 11.11.2026), CrUX-ключа нет. Скорость оценена косвенно (TTFB, вес ассетов). Последний реальный замер — 11.11: LCP 3,1 с, TBT 400 мс, mobile. Коммиты `fix: performance` / `fix: pagespeed improved` после этого не проверены.
3. **Яндекс.** Цифра «0 страниц в индексе» взята из аудита 11.11.2026 и **сегодня не перепроверялась**.
4. **Внешние ссылки.** Нет Ahrefs/Semrush. Вывод «нет внешних сигналов» основан на пустом результате поиска по домену и на брендовом запросе с 2 показами, а не на ссылочном отчёте.
5. **`site:` через Serper.** Оператор вернул 0 результатов; при подтверждённой индексации это скорее индикатор нулевой видимости, чем доказательство отсутствия страниц в индексе. Интерпретировать осторожно.
