## Выводы

1. **Главный блокер — домен.** Пока прод живёт на evgeny-zaiko.by, а весь SEO-фундамент (canonical, sitemap, OG, robots Host, GSC-коды) ссылается на eugene.zaiko.by, поисковики получают противоречивые сигналы: индексировать нечего (404), sitemap и canonical не резолвятся.
2. Решение о выборе домена — за владельцем: перенести Vercel-деплой обратно на eugene.zaiko.by **или** перевести все константы на evgeny-zaiko.by. Технически оба пути одинаковы (правка одного места + переменная окружения).
3. Сайт не подтверждён в GSC и Яндекс.Вебмастере — без этого нет данных по запросам собственного сайта и нет управления индексацией.
4. Яндекс.Вебмастер API недоступен текущим токеном; для кластера «перенос/ускорение сайта» это некритично, но для переобхода новых посадочных (IndexNow/переобход) нужен либо новый токен с нужными скоупами, либо ручная работа в веб-интерфейсе Вебмастера.
