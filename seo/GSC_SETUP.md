# Подключение Google Search Console — evgeny-zaiko.by (шаг B4)

Код верификации уже вписан в `app/layout.tsx` (meta `google-site-verification`), т.е. ресурс
в GSC создаётся/создан в формате URL-префикса. Оставшиеся шаги:

## 1. Проверить, что ресурс создан и подтверждён
1. Открыть https://search.google.com/search-console
2. Если ресурса нет — «Добавить ресурс» → тип **URL-префикс**: `https://evgeny-zaiko.by/`
   → способ подтверждения «HTML-тег» → код совпадает с вписанным в layout:
   `QLy0JClFzAhEnJUv2yUkP95bN0TUzdtDE784k9UN2pQ`.
3. **Задеплоить сайт** с этим мета-тегом (сейчас на проде ещё старая версия) и нажать
   «Подтвердить». Без деплоя подтверждение не пройдёт.

## 2. (Рекомендуется) Добавить ресурс-домен `sc-domain:evgeny-zaiko.by`
Тип «Домен» покрывает все поддомены и http/https. Подтверждение — DNS TXT-запись у
регистратора: скопировать TXT-значение из GSC → добавить запись `@` у регистратора →
«Подтвердить». TXT распространяется от минут до часов.

## 3. Дать доступ сервисному аккаунту (для автоматизации через google-seo-mcp)
1. В GSC: Настройки → Пользователи и разрешения → «Добавить пользователя».
2. Email: `google-seo-mcp-readonly@invertible-star-502409-f8.iam.gserviceaccount.com`
3. Роль: **Владелец** (для полного набора API) или «Полный» для данных.
4. Готово — после этого `gsc_list_sites` увидит ресурс, и я смогу снимать запросы/позиции.

## 4. После подтверждения
1. Sitemap: GSC → Sitemaps → добавить `https://evgeny-zaiko.by/sitemap.xml`.
2. Запросить индексацию главных страниц (Проверка URL → «Запросить индексирование»)
   — Google проигнорирует IndexNow, поэтому вручную: `/`, `/uslugi`, `/ceny`, `/cases`,
   `/blog`, 5 посадочных услуг.
3. Через 3–7 дней — первый отчёт по запросам/показам (шаг C3 цикла итераций).

## Критерий приёмки шага
`gsc_list_sites` возвращает `https://evgeny-zaiko.by/` (и/или `sc-domain:evgeny-zaiko.by`).
